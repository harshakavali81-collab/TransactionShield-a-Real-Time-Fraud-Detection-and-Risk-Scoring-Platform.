# Data provenance & responsible use
All data generated by `python scripts/generate_demo.py` are **synthetic**. They are generated from invented behavioral rules and do NOT contain real card numbers, customer identities, names, locations, or bank account information. The synthetic label is determined by a probabilistic simulation; the metrics **cannot be extrapolated to real payment fraud detection**. Production use requires consent, fraud-analyst review, representative labeled outcomes, data retention rules, access controls, compliance/security testing, and testing under real base rates and delayed labels. CSV generated at `data/raw/synthetic_transactions.csv` is not checked into Git by default.

Fields: `transaction_id`, `event_time`, `amount`, `hour`, `account_age_days`, `velocity_24h`, `prior_chargebacks`, `ip_risk_score`, `is_international`, `is_new_device`, `merchant_category`, `transaction_type`, and training-only `is_fraud`. No actual personal identifiers are required. The ID is an artificial demo key.
